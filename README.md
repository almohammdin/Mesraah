# مِسراح

منصة عربية لإدارة المهام والمساحات والأشخاص والمتابعات والإنجاز اليومي.

## v0.21.0

- وكيل متابعة يراجع كل ساعة أثناء دوام الأحد–الخميس 8 ص–5 م، وكل 3 ساعات خارجه وفي الويكند، ويتوقف 10 م–6 ص
- صندوق وكيل يوضح المتأخر والقريب والمتابعة المستحقة والنواقص المهمة
- صلاحيات آمنة: التحليل والتنبيه تلقائيان، والتغييرات الحساسة تبقى بموافقة المستخدم
- منع تكرار التنبيهات وسجل لنتيجة كل مراجعة
- خدمة Firebase مجدولة جاهزة لتشغيل الوكيل كل 15 دقيقة للحسابات التي فعلته

- تقويم يومي وشهري وسنوي
- تكرار فعلي للمهام وحذف مهمة واحدة أو السلسلة كاملة
- محادثة صوتية وكتابية تحفظ المهمة داخل مسراح أولا
- مزامنة ثنائية مع Google Calendar مع منع التكرار
- استيراد تلقائي عند فتح المنصة وكل 5 دقائق أثناء استخدامها
- تسجيل دخول وحفظ سحابي عبر Firebase
- ملف تصميم واحد ومسار تشغيل واحد دون تحميل طبقات الواجهات القديمة

## بنية التشغيل

- `index.html` هيكل الصفحة
- `mesraah-v0124.css` التصميم الكامل
- `app.js` نواة المهام والبيانات المحلية
- `moment-ui.js` مسار الإقلاع الوحيد للوحدات الحديثة
- `calendar-sync-v0112.js` المزامنة الثنائية مع Google Calendar
- `mesraah-voice.js` و`mesraah-voice-tools.js` المساعد الصوتي وتنفيذ أوامر المهام

مفاتيح الخدمات لا تحفظ داخل ملفات GitHub Pages.
