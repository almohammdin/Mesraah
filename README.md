# مِسراح

منصة شخصية لإدارة المهام اليومية، الجهات والمساحات، الأشخاص، المتابعات، الإنجاز والمكافآت.

## v0.3.0

- إعداد أولي للحساب واسم المستخدم
- تحية شخصية بعد حفظ الاسم
- إدارة الجهات والمساحات والأشخاص
- «على الطاير 🎙️» للإدخال الصوتي أو الكتابي
- مهام ومتابعات وإنجاز ومكافآت
- واجهة متجاوبة للجوال والكمبيوتر
- تخزين محلي مؤقت للنسخة الحالية

## المرحلة التالية

تسجيل الدخول وربط كل مستخدم بمخزنه الخاص، ثم ربط Gmail وGoogle Calendar والخدمات الأخرى.
